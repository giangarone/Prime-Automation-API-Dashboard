Wiring this page to real data

Every number on this page is generated by the MOCK block at the top of the script so the page is viewable standalone. Replace loadRecords() with a fetch against your own endpoint — the rest of the page only ever reads the normalized record shape below.

  • Record shape: { day, userId, strategyId, surfaceId, requests, inputTokens, cacheReadTokens, cacheWriteTokens, outputTokens, errors, rateLimited }
  • Org totals (spend, tokens) come from Anthropic's Admin API: GET /v1/organizations/usage_report/messages and GET /v1/organizations/cost_report, authenticated with an admin key. These group by API key and workspace.
  • Per-user and per-strategy attribution is yours to record. Anthropic does not know your user IDs or strategy IDs, so log one metering row per call in your own database — user, strategy, surface, and the usage block returned on every response (input_tokens, output_tokens, cache_read_input_tokens, cache_creation_input_tokens). Roll those rows up nightly and reconcile the totals against the cost report so billing drift is caught early.
  • Cost is computed client-side from the PRICING rates — update them when rates change, and keep cached-read at 0.1× and cache-write at 1.25× of the base input rate.
